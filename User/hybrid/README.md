# HYBRID selection

Карточная группа остаётся C, горячие CRC16, журнал, RX, config/status/snapshot — ASM.
`user_fun_hot.s` содержит исходные ASM-инструкции, общие хвосты и literal pools.
Выбранные холодные функции и относящиеся только к ним CFI-блоки исключены;
comm/diag/misc и оболочка expiry взяты из C. Определения общих данных остаются
единственными, в ASM. `Tests/test_hybrid_hot.py` проверяет сохранение исходной
последовательности инструкций, директив и литералов.

`cold_declarations.h` объявляет общие помощники. `HYBRID_LOCAL` убирает `static`
только у выбранных холодных C-функций гибрида. Обычный C-проект сохраняет
внутреннее связывание. idclear/fw_service/idindex/sector_runtime выбраны из C;
для остальных модулей измеренный C-вариант не уменьшил связанный BIN.
Измерения групп и ограничение по размеру описаны в
`Tests/HYBRID_MEMORY_20261006.md`, раздел «Этап 2».

`string_select.h` выбирает `__iar_small_memcmp` для пути карты. При обновлении
исходного ASM следует повторить разнесение с сохранением ссылок между телами,
хвостами, литералами и CFI, затем заново сравнить связанные образы и пути.
