# HYBRID

Открыть три проекта можно через `DomovoiNext_compare.eww`.

Исходники выбирает `DomovoiNext_HYBRID.ewp`: C-группа карты через `HYBRID_CARD`, остальные user_fun — ASM с единственной копией состояния. idindex и sector_runtime — C по размеру; общие драйверы прежние. Копий исходников здесь нет.

`string_select.h` сохраняет выбор библиотечного `__iar_small_memcmp` из IAR C High/Size для поиска ID. Без этого малая единица компиляции HYBRID получает общий memcmp и замедляет перебор. Это выбор уже связанной в C библиотечной реализации, без изменения алгоритма; зависимость от IAR 9.50.1 отражена в отчёте.
