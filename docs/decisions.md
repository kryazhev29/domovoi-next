# Решения владельца

- 2026-10-14 — USB-журнал монтажника 108/109 в обоих профилях. В базе TX уже передаёт закреплённый источник, поэтому журнал идёт через собственную очередь на 4 кадра до 63 байт, не занимает WORK_REPLY и уступает ответам (без очереди на плате терялось 11–14 %). Длинная строка AT — несколько кадров по 45 байт с битом продолжения, без обрезки; насыщаемые потери, сброс маски по USB-сессии. События снимаются после подтверждённой публикации общей точкой sync/async; PDU/TCP/SMS без содержимого. NextConfig: общий потоковый декодер и повтор 108 после ПИН. Плата №1 14.10: потерь 0, опрос статуса не страдает. [Протокол](protocol/usb_log.md).

- 2026-10-13 — Linkpro: каждый USB 112 продлевает наведение антенны на 60 с; низкоприоритетный QENG в интервалах 2 с, полный цикл прежний (30 с), сервер/звонки/SMS первыми. Один новый таймстамп, без задач и буферов. USB 112 v5 добавляет band/dl_bandwidth в 94/95 (98 байт с CRC), старые поля на прежних местах; ошибки QENG и сброс очищают обе величины в 255. Главная и «Связь» NextConfig используют общие оценки и историю 10 минут, v3/v4 совместимы. На плате не проверено.

- 2026-10-13 — Паузы питания SLM336 обслуживает SysTick независимо от тяжёлой инициализации Flash. Подсчёты остаются синхронными до регистрации и статусов; ISR только GPIO/время, без AT/SPI/команд приложения. Сроки 7/5 с, PWRKEY 2 с и загрузка 2 с сохраняются. USB 112: этап питания — до готовности главного цикла, сумма этапов = настоящее время. Плата и сервер не затрагиваются; новое поведение на плате не проверено. [Отчёт](history/MODEM_STARTUP_20261013.md).

- 2026-10-12 — Звонок: проверка номера → открытие → ATA → ~1 с → AT+CHUP. ATH на SLM336 возвращает OK, но не завершает ни снятый, ни неотвеченный вызов (проверено на плате №1 12.10); CHUP выбран по MeiG Common V2.24 §7.4. Во время загрузки FW (бит 11) — CHUP без ATA, проверки доступа и записи прохода; команда 8 не исполняется, карты работают. При возврате данных срок TCP ACK обновляется: голосовая пауза не закрывает исправный сокет. [Проверки и AT-лог](history/SLM336_HANGUP_20261012.md).
