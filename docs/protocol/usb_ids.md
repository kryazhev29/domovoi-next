# USB 116: резервная выгрузка базы ID

Только по USB, после ПИН (команда 102). Нужна NextConfig для кнопки «Выгрузить базу» (Алексей 26.10.2026).

Запрос: тело 2 байта, первая ячейка (1–50000, младший первым; 0 = 1).

Ответ 116:

| Байт | Значение |
|---|---|
| 0 | 0 — прочитано; 1 — флеш занята или отказ чтения, повторить с той же ячейки |
| 1–2 | следующая ячейка для запроса, 0 — база пройдена |
| 3 | число записей N (0–7) |
| 4… | N записей по 32 байта, как в памяти и в команде 13 (номер ячейки, ID, группа, дата запрета, время действия, тип, проходов в сутки, счётчик, резерв) |

За один запрос просматривается не больше 256 ячеек: на пустой части базы ответ без записей, но со следующей ячейкой.
Пустые ячейки пропускаются по тому же правилу, что и при стартовом скане (номер 0xFFFF или последний байт резерва 0xFF).
Счётчик проходов отдаётся с учётом слоя счётчиков.
