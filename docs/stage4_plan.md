# Этап 4 — план, 06.10.2026

База: `8a89626`, `compare/c-asm`. Изменения локальные, без коммитов,
прошивки платы, сервера, загрузчика, изменения адресов и протокола.
Общие драйверы используются C/ASM/HYBRID; раздельные реализации должны
давать одинаковые результаты. Стенд и заказчик проверяются отдельно.

Оценки ниже — верхние пределы прироста BIN для каждой реализации, не
измеренные результаты. RAM не увеличивать. Итоговый BIN должен быть меньше
базы. Время Unicorn — число инструкций и отдельно время модели NOR;
это не измерение тактов Cortex-M3 или времени физической платы.

Порядок: 0 → 1 → 2 → 3 → 4 → 5 → 6 → 7. Не более трёх
реализационных подходов на задачу без доказанного результата; откатить
неудачный код, сохранить причину и перейти дальше. Для поиска размера —
стоп после пяти последовательных шагов с выигрышем менее 30 Б.

База стенда ASM/C/HYBRID: 88513/86969/88689 Б; заказчика:
86261/84633/86433 Б. Свободная RAM: 3232/3584 Б соответственно.
Сначала воспроизвести эти числа свежей сборкой HEAD. После каждой задачи
зафиксировать BIN, RO/RW, инструкции, NOR-время и проверки. После последней
правки повторить обязательные проверки; временные файлы — только `%TEMP%`,
итоговых JSON не более трёх. Итог: `Tests/STAGE4_20261006.md`, включая
невыполненные цели и ограничения модели/физических испытаний.

- В итоговом дереве оставлены 0 (USB без ожидания TX) и 5 (аппаратный CRC FW).

  +1,296% при пределе +1%; Wiegand восстановлен байт в байт HEAD.

  проверки находятся в `Tests/asm/stage4_design_probes.py`. Новые пути
  хранения и их требуемые показатели не реализованы.

  эксперименты 7 с .inc не дали отдельно выбираемые единицы трансляции.
  Оба изменения откатаны, HYBRID-условия остаются.

  `Tests/STAGE4_20261006.md`. Этап целиком не закрыт; невыполненные задачи
  не засчитываются как зелёные feature-тесты.
