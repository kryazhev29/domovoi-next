## Воспроизведение

PowerShell; окружение как в docs/cleanup_findings.md:

```powershell
$env:PYTHONIOENCODING='utf-8'
$env:PYTHONDONTWRITEBYTECODE='1'
$env:PYTHONPATH='C:\Users\kryaz\AppData\Local\Temp\codex-deps'
$env:DOMOVOI_ZIG='C:\Users\kryaz\AppData\Local\Temp\codex-zig\zig.exe'
$env:DOMOVOI_COMPARE_BUILD='C:\Users\kryaz\AppData\Local\Temp\domovoi-tests-build\verified'
$python='C:\Users\kryaz\AppData\Local\Temp\codex-py311\python.exe'
foreach ($config in 'Release','ReleaseCustomer') {
  foreach ($project in 'C','HYBRID') {
    & $python Tests/build_iar.py --project $project --config $config --build-root $env:DOMOVOI_COMPARE_BUILD
    if ($LASTEXITCODE) { throw 'Сборка не прошла' }
  }
  & $python Tests/run_all.py --project HYBRID --config $config
  if ($LASTEXITCODE) { throw 'Тесты не прошли' }
  & $python Tests/asm/c_vs_asm_compare.py --paired --config $config --output "$env:DOMOVOI_COMPARE_BUILD/paired-$config.json"
  if ($LASTEXITCODE) { throw 'Сравнение не прошло' }
}
```

Каждый run_all создаёт свежую копию тестовых исходников в TEMP, поэтому удалённые файлы не могут попасть в прогон из старой папки стенда.

## Итог и ограничения

Тестовая справочная копия и полный ASM сняты; проверяется настоящий рабочий код. Переименование c_vs_asm_* оставлено предложением. Исполняемые исходники User/c, Modules, board.*, main.c и Bootloader не изменены; удалены только неиспользуемые файлы User/asm. Заголовок 0x08008000, векторы 0x08008200 и ограничение загрузчика 32 КиБ сохранены.

Результаты относятся к компиляции и моделям собранного ELF. Проверки физического устройства, реальных сроков периферии, платы, сервера, SMS и команд доступа не выполнялись. Одиннадцать предупреждений сохранены с конкретными причинами выше; доказанный предел стека по Ls016 не заявляется. Коммит не создавался по поручению владельца.
