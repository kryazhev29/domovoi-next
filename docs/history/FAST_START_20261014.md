## Результат и границы

На одинаковой синтетической модели от PC13 до принятого ответа регистрации сервера:
2G **13,09 → 8,52 с**, LTE **7,39 → 5,51 с**, auto **7,36 → 6,84 с**.

Снятие программных пауз не сокращает обязательную регистрацию оператора; наблюдавшиеся заказчиком 9,6–10,6 с поиска сети программно гарантировать нельзя.

После просьбы убрать лишние байты удалены повторный разбор CREG/CGREG/CEREG, устаревший выбор alternate для NETWORK,
повторяющаяся развилка APN/PDP и преждевременная запись dirty на каждом успешном QIACT.
Три новых признака занимают битовые поля в прежнем выравнивании attempt. Новых буферов, очередей и heap нет.
