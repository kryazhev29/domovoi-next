# Чистка «ФОТО», 07.10.2026

База `3b30322`, worktree `domovoi-photo`. Плата, сервер, загрузчик и замороженный ASM-проект не использовались. Коммитов нет по поручению владельца.

## Результат и интеграционная граница

Фото: **4488 Б** (код 4444 + константы 44), RAM **116 Б**. Цель ≤4500 Б достигнута в C/HYBRID, Release/ReleaseCustomer.

До перевода: модуль ASM в HYBRID **7904 Б** (7572 + 332), C **7944 Б** (7612 + 332); RAM обоих 132 Б. Измерены свежие карты IAR, без сборки `DomovoiNext_ASM.ewp`. Перевод сам по себе +40 Б, чистка C −3456 Б; результат относительно исходного HYBRID **−3416 Б**, RAM −16 Б.

Изменены только разрешённые исходники фото, его тесты, строка фото в HYBRID и отчёт. В C `.ewp` уже указан C-файл, строка оставлена. Чужие `docs/cleanup_findings.md` и появившийся во время работы `docs/board_v5.md` сохранены.

**Для слияния обязателен дифф ниже.** Чужой `user_fun` ещё вызывает удалённые функции. Поэтому сборки и полные тесты выполнены в TEMP-копии с предлагаемым диффом; чужие исходники рабочего дерева не менялись. До применения диффа дерево самостоятельно не собирается. Совместимые заглушки не оставлены.

Постоянный помощник `Tests/build_photo_cleanup.py` воспроизводит копию и дифф. Сборки используют настоящие `iccarm`, `iasmarm`, `ilinkarm`, `ielftool` по командам `IarBuild -jsondb`; успех оболочки `IarBuild -build` не заявляется. ICF исходные: заголовок `0x08008000`, векторы `0x08008200`, загрузчик 32 КиБ.

Новый заголовок: номер [0..3], размер [4..7], метка 0x32504850 [8..11], полный ACK [12]. JPEG начинается с байта 13. Метка публикуется последней; байт ACK программируется в 0 при полном подтверждении.
