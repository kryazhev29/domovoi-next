# Ночная проверка Домового, 3 октября 2026

Ветка `codex/comm-core`, плата №1 COM5, HW139/v5/SLM336. Продолжение `COMM_REVIEW_20261003.md`.

## Подтверждённые ошибки и исправления

| Сценарий | Последствие | Исправление |
| --- | --- | --- |
| Незавершённая строка URC при свободном AT | Все последующие команды отклонялись BUSY без восстановления | Ограничено ожидание фрагмента; ошибка передаётся восстановлению. `a78a159` |
| Ответ ping/DNS одновременно с подтверждением TCP | Исправная сеть считалась недоступной | Асинхронные ответы разбираются также во время OP_ACK. `0e8d81b` |
| Старт с неверными настройками, затем сохранение исправленных | Модем оставался выключенным до перезапуска CPU | Успешная команда 12 запускает только модем в SLM_IDLE. `61fcd00` |
| Ошибка чтения образа из внешней Flash | CRC мог подтвердить оставшиеся в буфере данные; заголовки использовались без успешного чтения | Проверяются результат чтения, размер и выравнивание; ошибки чтения блоков и возобновления прекращают обновление. `8306241` |
| Ошибка чтения при линейном поиске ID | Запись могла считаться найденной после неудачного чтения | Поиск прекращается без подтверждения ID. `4391647` |
| Ошибка чтения/записи временного ID | Очередь продвигалась и выставлялся readyID при неудачной записи | Указатель и признак очереди меняются только после успешной записи. `4391647` |
| Ошибка чтения/записи/стирания фотографий | Непрочитанный заголовок считался свободным местом; ошибки могли пропустить проверку копии или продвинуть отправку | Ошибка сканирования отличается от свободного хвоста; снимки и позиция отправки сохраняются, восстановление и очистка не продвигаются после отказа I/O. `4391647` |

В тестах воспроизведены отказы до исправления. Для Flash моделировался как отказ без изменения буфера, так и возврат ошибки после переноса ожидаемых байтов. Физическую неисправность Flash на плате не создавали.

Сравнение одинаковым инструментом: 12021 → 12075 байт Flash, RAM 2320 → 2320. Порог не меняли. Это сумма отдельно собранных модулей, а не размер связанного приложения. Сравнение сохранено в `Release/comm-review/budget-baseline/comparison.json`.

Финальная сборка: readwrite code 516 байт, data 19459, heap 5120, стек 4096; промежуток до fault_record 480 байт. Это не оценка свободного стека при всех сценариях. Дополнительной статической RAM ночные исправления не потребовали.
