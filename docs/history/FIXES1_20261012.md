## Отказ записи #add

В исходном коде и `sms.md` нет ответа об ошибке выполнения записи временного ID. Поэтому при корректном формате, но отказе записи SMS-ответ не отправляется; ложных `- Ok`, `Format not correct` и события 67 нет. Предлагаемый текст для отдельного согласования: `ADD: Error "Write failed"`. В код он не добавлен. Существующий ID считается успешным идемпотентным добавлением.
