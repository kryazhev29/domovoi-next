## Уборка Windows

`temp_cleanup.TemporaryDirectory` повторяет удаление при PermissionError: немедленно, затем через 0,1/0,2/0,4/0,8/1,6 с. После исчерпания попыток либо другой ошибки OSError каталог остаётся в TEMP, в stderr/лог записывается `Уборка TEMP: оставлен каталог ...`. Ошибка уборки не меняет результат проверки; исходное исключение проверки сохраняется.

Host-стенды и вложенные мутации используют этот контекст напрямую. Обёртка запуска применяет его также к стандартному tempfile в ASM-стендах, включая CRC differential, без изменения их файлов. Постоянные каталоги артефактов и копия исходников профиля остаются в TEMP для разбора результатов, как раньше.
