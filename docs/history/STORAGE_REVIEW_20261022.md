- **2.1:** единственный вызов `flash_exec_cancel` — `user_savereset`, после которого
  `store_reset_requested` запрещает `idindex_runtime_begin`, так что стартовый скан

  после перезагрузки скан и сверка метки индекса начинаются заново. Пересборка
  64 секторов не возникает. Код не менялся.
- **3.4:** 255 чтений по 16 Б при старте — единицы миллисекунд на SPI 18 МГц;
  пакетное чтение добавило бы буфер и код без заметного выигрыша. Не менялось.

## Проверки

Стенды ELF (`Tests/asm`, настоящий машинный код обоих профилей, модель NOR):

- `table`: новая проверка `test_cancel_after_write` — отмена посреди расчёта CRC
  (1,6 МБ): граница 50048, `id_used_bytes`, число ID опубликованы, автомат
  завершается за ≤5 проходов; при неизвестной границе полный пересчёт доводится
  до конца и публикует итог.
- `photo_edges`: `wrap_keeps_oldest` — снимок 65535 Б (17 секторов) при остатке
  16 секторов: заворот запрещён, если `pr.oldest` в хвосте или равен указателю;
  разрешён при `pr.oldest` в середине кольца, указатель переходит на начало.
- `counter pages`: `replace_keeps_crc` — команда 13 на сектор без строк слоя
  сохраняет готовый кэш, ответ несёт точную CRC; сектор со строкой слоя даёт
  точную CRC после согласования слоя.
- `reset runtime`: режим `log paused` — журнал с ожидающей записью и паузой 30 с
  не задерживает перезапуск (< 5 с модели); мутация `reset-waits-paused-log`.
- `expiry`: отметка срока через слой (две записи, 10 Б, база не переписана,
  логический образ содержит 56); заглушки `counter_write` 2/0/−1 — журнал
  сектора и отказ; дифференциал с эталоном сравнивает логический образ;
  отмены по фазам SJ и отказы NOR проверены для слоя и для журнала.
- `config`: `cursor_without_marker` — строка курсора над образом без маркера
  даёт `last=0`, с маркером сохраняет значение.
- `Tests/asm/test_storage_review_mutations.py`: возвраты шести дефектов
  (метаданные при отмене, CRC после отмены, заворот фото, сброс кэша CRC,
  отметка срока только журналом, принудительный маркер) собираются из копий
  исходников и обнаруживаются своими стендами; включено в `--full`.
