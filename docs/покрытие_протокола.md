## Найдено и исправлено этой ночью

- **Команда 18 / пакет 15**: не передавался номер блока (E565), блок N брался со сдвигом на один (offset N*16000 вместо (N-1)*16000), номер >100 читал мимо базы. Исправлено на ветке claude/idbase, 843c522. **Сервер СофтЭксперт мог подстроиться под старое поведение — проверить на их сервере.**
