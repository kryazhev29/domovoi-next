4 159 → 3 705, RAM 213 → 212. Диагностика осталась 128 байт;

фазы и переходы. Правила и фаза упакованы в байт, смещения команд — uint8.
Общий API имеет имена `comm_modem_*`; прежние имена сохранены макросами.

копии и snprintf убраны. Длительности и кольцо сбоев пишет `slm_record`.
