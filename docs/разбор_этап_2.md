# Разбор этапа 2 (архитектор, 02.10.2026)

Принят. Коммиты 2fbb00b, 76b8b0d, 1d04b8b. Тело по длине, поздние ответы, запрет рекурсии, статические буферы — как надо.

## Ответ на вопрос о восстановлении

Ждать старый финал перед `AT` не будем: если модем его потерял, получим лишний перезапуск по питанию. Вместо голого `AT` синхронизация командой с узнаваемым ответом:

- после таймаута: если идёт тело QIRD — дочитать его по длине (как сейчас), затем сразу послать `AT+CMEE?`;
- синхронизация считается успешной, только если `OK` пришёл после строки `+CMEE:`; одиночные `OK`/`ERROR` до неё — поздние ответы старой команды, их игнорировать;
- общий срок восстановления 2000 мс; не уложились — «модем не отвечает» наверх.

Команда есть у всех трёх модемов. Это сделать первым пунктом этапа 3, с тестами: потерянный старый финал, поздний старый OK до `+CMEE:`, поздний старый OK после синхронизации.

## Память

Флеш 4,5 КБ по gcc больше моей оценки 3 КБ. Окончательно сверю по карте IAR, когда модуль подключим. Если по IAR выйдет больше 3,5 КБ — ужимать (таблица строк URC, общие функции разбора чисел).
