## Уточнения заказчика

- Аппаратный вход в загрузчик, индикация и номер HW уже существовали. Не считать их новой разработкой.
- Загрузка прошивки с сервера во внешнюю Flash уже есть в исходной FW: команда 19 передаёт метаданные, запрос 13 получает очередной блок, команда 20 принимает блоки по 1024 байта. Это подтверждено исходным коммитом 05e9248.
- Источник образа — сервер или файл через существующее сервисное ПО. Версия и билд берутся из имени файла либо команды сервера 19.
- В новом загрузчике дешифрования нет. Старое шифрование нужно для совместимости при передаче переходного приложения старому загрузчику.
- boot_tool и Domovoi Service созданы для внутренней отладки. Заказчик не просит отдельную сервисную программу; штатная загрузка должна быть в его ПО. В финальном комплекте GUI помечена как внутренняя утилита; команду 110 она не отправляет.
- Размещение дампов на усмотрение разработчика. Главная цель — восстановить рабочую прошивку и связь после неудачного обновления, выдерживая потерю питания и перезагрузку.
- Для пробной новой FW использовать существующий алгоритм GSM: три попытки подключения, перезапуск модема, затем вместо обычной полной перезагрузки запросить откат. Успешную регистрацию новой FW использовать для подтверждения обновления. Эти изменения ЕЩЁ НЕ РЕАЛИЗОВАНЫ.
- Тестовый сервер и контроллер у владельца есть; параметры доступа и сценарий испытаний не переданы.
- Плата с наклейкой FW 48 содержит старую FW: центральная кнопка при включении — загрузчик; кнопка у SIM при включении — заводской сброс. Не путать.

## Последнее уточнение миграции

Старый конфигуратор устанавливает только новую FW. Затем пользователь выбирает
файл загрузчика по фотографии платы в новом сервисном ПО и вручную запускает
замену. Старый HW недостоверен; до замены передаётся 0. Сервер обновляет только FW,
замена загрузчика разрешена только через USB сервисного ПО.

Замена загрузчика — разовая операция при переводе платы из старой системы в
новую. Серверных команд и запросов такой замены в системе нет и не требуется.
