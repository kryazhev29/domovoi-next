# Загрузчик ДОМОВОЙ NEXT

Плата v5 HW139, STM32F103CB. IAR-проект DomovoiBoot.ewp: только Release.
Сборка из корня: `python Tests/build_iar.py --boot`; точное окружение описано в ../AGENTS.md.
Загрузчик занимает первые 32 КиБ; заголовок приложения 0x08008000, векторы 0x08008200.
Обновление работает через сервер и USB; версия загрузчика 0x32, пробный запуск с откатом.

boot_core/boot_main/boot_platform — протокол, переходы и периферия; app_update — проверка образа из приложения.
boot_manual — USB-обновление; boot_tool.py — консольный клиент; desktop_app/desktop_transport — настольный клиент.
Инструкции ручного обновления: MANUAL_UPDATE.md; интерфейс: DESKTOP.md. Их выполнение требует согласованного сценария.
build_gcc.py — отдельная сборка v5 ARM GCC, build_desktop.ps1 — упаковка настольной утилиты; tests/ — тесты загрузчика и клиента.
Общий полный прогон проверяет IAR ELF загрузчика, передачу и USB-ожидание; модель не проверяет электрические сигналы платы.
