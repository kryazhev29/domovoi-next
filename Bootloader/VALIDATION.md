# Проверки 14 сентября 2026

- ARM GCC 12.3: полная сборка и линковка v5, MINI, MODEM выполнены.
- v5: text 10628, data 232, bss 3872 байта; MINI/MODEM: text 10612, data 232, bss 3872.
- Каждый BIN имеет размер 32768 байт; векторы по 0x08000000, ID по 0x08007FFC.
- C-тесты: 206 точек полного/частичного сбоя установки и 260 точек отката/очистки.
- Отрицательные проверки CRC, HW, размера, векторов; пустая Flash, повтор восстановления,
  максимальный образ и имена файлов.
- USB: все разбиения BEGIN на два фрагмента, неверный CRC/длина, переполнение,
  поток мусора, повтор блока, неверное смещение и преждевременное завершение.
- Python: 4 теста CRC, старой упаковки, адреса приложения и вложенного образа.
- boot_core.c дополнительно выполнен с инструментированием undefined-behavior sanitizer;
  тестовая модель с setjmp/longjmp собрана отдельно без инструментирования.
- Адаптер приложения с DOMOVOI_BOOT_MIGRATION скомпилирован ARM GCC через временную
  совместимость с IAR intrinsics. В секции replace_ram нет внешних релокаций/вызовов.
- Изменённый user_fun.c прошёл GNU syntax-only после адаптации анонимного глобального
  union IAR во временной копии. Это НЕ полная сборка приложения.
- IAR 9.2: сборка загрузчика заблокирована LMS001, лицензия компилятора отсутствует.
- Реальная плата, USB, SPI, питание и переходная прошивка не проверялись.

В GCC остаются предупреждения исходного USB SDK о pragma/comment и bare-metal main.
Стендовые образы не означают подтверждённую пригодность для массового обновления.
