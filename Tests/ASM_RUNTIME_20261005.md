# Перенос runtime на ARM Thumb-2, 05.10.2026

База: 3450335, codex/comm-core. Плата, COM, прошивка, сервер, SMS и реле не использовались.

## Этап A: ранее переделанная исполняемая логика

В IAR-проекте семь C translation units заменены самостоятельными ASM-модулями:
`user_fun`, `flash_w25`, `memory`, `photo`, `crc`, `idindex`, `user_comm`.
Перенесены целые модули, чтобы не оставлять C-условия вокруг ASM-ядер.
Полный список 309 функций — `asm/runtime_inventory.json` (по модулю).
Он включает server_rx_* (бюджет, CRC, reset, владение входом), w25_async_*,
mem_config_* и cfg_* (публикация/очистка/ошибки), store_* и user_storage_*,
log_async_*/log_storage_poll, fw_async_*/fw_storage_poll, crc16_append_ff,
ID-поиск/счётчики/хеш-обвязки, фото и вызывающие функции user_comm.

ASM получен из установленного IAR 9.50.1, проверен повторным ассемблированием
и хранится в репозитории. Обычная сборка **не компилирует C-эталоны** и не
генерирует ASM автоматически. Условия, циклы, ожидание, отмена и ошибки находятся
в `.s`. `Tests/asm/port_runtime.py` — явный инструмент воспроизведения переноса.
Устранена несовместимость listing с assembler: CFI FunCall вынесен перед IT;
инструкции IT-блоков сохранены. AAPCS/PRESERVE8/REQUIRE8 и CFI сохранены.

C-эталоны находятся только в `Tests/asm/reference/User`. В production C остались
объявления отладочных типов `User/runtime_layout.c` (36 байт readonly data)
и не затронутые этим переносом модули периферии/связи/загрузчика. В main и USB
прежние связующие вызовы сохранены. `User/sector_journal.c` пока общий неизменённый
startup/recovery и синхронный API; runtime таблиц заменяется следующим этапом.
Этот этап не объявляет таблицы или фотографии пошаговыми.

Проверки:

- Все `.text/.rodata/.data/.bss` семи повторно собранных ASM-object побайтно
  совпадают с независимыми IAR C-object: 309 функций, `verify_runtime_port.py`.
- Общий набор: 65/66 сразу; единственный отказ — CRLF перемещённых тестов.
  После нормализации `check_comm_sources.py` PASS: все 66 групп прошли.
  Мутационные наборы выполнялись последовательно, затем полная IAR Release.
- Мутации реальных Thumb-инструкций W25: BUSY, timeout, verified-success — 3/3.
- Итоговый ELF: W25 ownership/status/readback/timeout PASS, максимум 983
  инструкции poll; RX границы/ABI/бюджет PASS; события и FW вызывающие цепочки
  PASS; page/heap, storage faults, persistence, photo heap PASS.
- Сборка: 0 ошибок, прежнее Ls016. Загрузчик не менялся.

Числа здесь — инструкции Unicorn с моделью NOR/SPI, **не такты или миллисекунды**.
Baseline таблиц: 431747 (1 ID) / 556584 (63 ID) за синхронный вызов;
CRC префикса фото 4095: 40586. Стек этих путей до перехода: 1128/1040/120 байт.
Результаты RX/FW/events после ASM-переноса: `asm/runtime_port_*.json`.
Heap и CSTACK по 4096. Статическая сумма readwrite data сохранилась: 19507.
readonly code: 74949 -> 75545; readonly data: 6940 -> 6976; BIN: 81889 -> 82521.
RAM-code 516, адрес заголовка 0x08008000, векторы 0x08008200 сохранены.
Измеренный photo heap 1784/4096 при одновременных photo_s + USB1040 + block534.

Гарантии 50 мс нет. Синхронные пути таблиц и фото на этом этапе ещё сохранены,
но уже исполняются из ASM. Незавершённые последующие этапы перечисляются отдельно.
